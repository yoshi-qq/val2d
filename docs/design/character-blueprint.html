Val2d Character Blueprint

Everything needed to draw an agent's sprite sheets by hand in Aseprite. The examples use Kestrel; the file docs/design/CHARACTER_SHEETS.md has the same rules as text. 12 states are required, everything else has a fallback.

See-through, invisible and tinted looks are done by the game with transparency and tint, so they need no sprites. Forms may use up to 8 extra colours.

Files and workflow

  • assets/agents/{key}/{key}.aseprite holds all 16×32 states as tags; dead (32×16) and portrait (32×32) get their own files.
  • Layers: guides (locked, hidden on export, from docs/design/templates/character_guides.png), body, optional fx.
  • Export every tag as a horizontal strip {key}_{tag}.png without spacing. The command below is untested.
aseprite -b assets/agents/vesper/vesper.aseprite --ignore-layer guides --split-tags --sheet-type horizontal --sheet assets/agents/vesper/vesper_{tag}.png
python docs/design/check_agent_sprites.py vesper

The check writes the red enemy variants and lists problems: size, frame count, free columns, reserved colours, colour budget.

Sheet layout with Kestrel

Light slots are the minimum frame count, dark slots are optional extra frames. Empty rows are optional states Kestrel doesn't have yet.
