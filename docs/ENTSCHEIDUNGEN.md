# Decisions

Format: date · who · area · wording

- 11.11.2026 · Christian · Principle · Always as close to Valorant as possible; deviate only if 2D truly makes a mechanic impossible.
- 11.11.2026 · Christian · Gunplay · Spread like Valorant: standing still, first bullet exact; moving and spraying random within a fixed range.
- 11.11.2026 · Christian · Gunplay · Hit zones via lateral distance (exact sprite widths) and the cursor's depth distance (head = center point, large allowed deviation), only on the same height level; deviations in the game config.
- 11.11.2026 · Christian · Gunplay · Wall penetration according to penetration level.
- 11.11.2026 · Christian · World · Scale in real meters, values from the patch notes with patch number.
- 11.11.2026 · Christian · Presentation · Top-down with height levels; vision cone as default, all-round vision as a lobby rule; camera pushed forward (player setting); pixel art in our own style.
- 11.11.2026 · Christian · Game flow · Teams 1v1 to 5v5; simple bots in the first version; match length adjustable, default as original; sound rings as a lobby setting, off by default.
- 11.11.2026 · Christian · Networking · Host = player 1 as default, dedicated server process possible. Internet mode peer-to-peer via public STUN servers, initially without relay. pickle only in the old LAN mode.
- 11.11.2026 · Christian · Scope · First version: Unrated, Ascent + simple 1v1 map, Omen + Jett, all weapons. After that: agents, modes, maps.
- 11.11.2026 · Christian · Packages · graphy and networking as GitHub repos under yoshi-qq, installed editable; import names stay the same.
- 11.11.2026 · Christian · Gunplay · Hit logic confirmed in the demo. Same level and line of fire through the enemy: always at least a leg hit. Camera rotates along, aiming always straight up; x/y = screen axes.
- 11.11.2026 · Christian · Gunplay · Head narrowly missed (within body width): body. Cursor on a different level: miss. Enemy sprites stand upright on the screen.
- 11.11.2026 · Christian · Graphics · Scale 16 px = 1 m (character 16×32, tile 32×32 = 2 m, view 480×270 native, ×4). Light from the top left.
- 11.11.2026 · Christian · Graphics · Outline: outer edge in a dark shade of each material's own color, within the sprite width; hit widths count without the outline.
- 11.11.2026 · Christian · Graphics · Team identification: sprites team-neutral, enemies with a red outline as in Valorant; color later a player setting.
- 11.11.2026 · Christian · Graphics · Shading: two levels per material (base tone, shadow), as in the existing assets. Concept: docs/design/sprite-konzept.html
- 11.11.2026 · Claude Code · Technology · New game core gameplay/ (without pygame, command-driven, JSON snapshot instead of pickle), playable via play.py against bots. Old path main.py stays unchanged.
- 11.11.2026 · Claude Code · Values · All game values are estimates in gameplay/data/*.json (source per file), hit zones and lobby defaults in config/game_config.json.
- 11.11.2026 · Christian · Graphics · Logo: crosshair design in logo.png, icon.ico and playercard.png (docs/design/logo-entwurf).
- 11.11.2026 · Christian · Language · Everything in English: game text, code, data and docs. Sprite file names stay as they are.
- 11.11.2026 · Christian · Content · Agents, abilities and weapons live in Python config files (config/agents.py, config/content/weapons.py) that Christian edits directly; they replace gameplay/data/agents.json and weapons.json.
- 11.11.2026 · Christian · Weapons · Roster of 20 guns plus knife from Christian's weapon overview (weapon classes, prices, magazines); other values estimates.
- 11.11.2026 · Claude Code · Abilities · Abilities are generic building blocks (21 kinds: smoke, wall, flash, zone, blast, wave, sensor, alarm, tripwire, dash, hop, teleport, anchor, heal, stim, shield, revive, reveal_all, overdrive, immunity, decoy) plus ten statuses (blind, nearsight, concuss, slow, vulnerable, decay, suppress, detain, deaf, stim). Agents only combine blocks.
- 11.11.2026 · Claude Code · Agents · Eight new agents: Vesper, Rook (Duelist), Tamsin, Okoro (Initiator), Juniper, Nyx (Controller), Harrow, Sable (Sentinel); Kestrel and Marrow kept.
- 11.11.2026 · Claude Code · Wording · The objective is called "bomb" in all player-facing text; code identifiers and file names with "spike" stay.
- 12.11.2026 · Claude Code · Maps · Material per wall and floor: config/content/materials.py (WALLS with tile, penetration, sight, height; FLOORS with tile). Map files use "mat" per wall and "floor"/"floors"; walls without material keep the old Werkhof tiles. Gasse uses the common set.
- 12.11.2026 · Claude Code · Maps · Map objects and decals: config/content/materials.py OBJECTS and DECALS; map files use "objects" (pos or rect, rot in 90° steps) and "decals". Blocking objects become walls; the spawn barrier blocks only during the buy phase and does not block sight.
- 12.11.2026 · Christian · Packages · netplay as its own package, local in Pakete/netplay and private repo yoshi-qq/netplay; push only after the phase report.
- 12.11.2026 · Claude Code · Network · Val2d networks only via netplay (gameplay/netgame.py): LAN over networking (TCP, JSON) with discovery, internet over UDP with STUN and join code. The old TCP code in gameplay/net.py is reduced to helpers (commands, snapshots, events).
- 12.11.2026 · Claude Code · Network · Without an own server, a host behind a restrictive router is only reachable through a reply code from the guest (host enters it); a relay comes later through the same interface.
- 12.11.2026 · Claude Code · Graphics · The new game code (play.py, menu.py, map_editor.py, sprite_bank.py) draws with pygame-ce directly, not through graphy: the camera rotates the whole world every frame and sprites follow the character-sheet states, which graphy's render objects do not cover. graphy stays the package for the old code path; Christian may decide to move the drawing into graphy.
- 12.11.2026 · Claude Code · Code · The old game path (main.py, handlers/, classes/, mapEditor.py) is left unchanged and unused; play.py is the entry point. Removing it is Christian's call.
- 12.11.2026 · Claude Code · Gunplay · Spray: automatic weapons keep the first two bullets on target, then drift to a per-weapon side with a sway (procedural pattern), blurred by random spread.
- 12.11.2026 · Claude Code · Movement · Ground height is continuous: ramps rise evenly toward the platform they lead onto, stepping off a ledge keeps the current height and falls, ground higher than step_up (config/rules/) blocks like a wall. The screen lifts figures by ground plus jump height. Steps are short soft taps (0.07 s) without a low tail.
- 12.11.2026 · Christian · Content · Agents, abilities, statuses and maps are modular: one file per agent (config/content/agents/), statuses as data (config/content/statuses.py), abilities composed from registered targets, triggers and effects (gameplay/kit), own mechanics in config/content/mechanics/, maps optionally in Python (gameplay/mapkit.py). Rules and game config are Python files (config/rules/, config/settings/); the JSON versions are gone. How to: docs/MODDING.md.
- 12.11.2026 · Christian · Interface · Esc never quits: in menus it closes the open page, in a match it opens the pause menu. Alt+F4 asks first; a second Alt+F4 quits at once.
- 12.11.2026 · Christian · Interface · HUD at the bottom and the sides; the upper middle (the view ahead) stays free. Hold F1 shows ability descriptions.
- 12.11.2026 · Christian · Sight · The darkened area shows what the player really sees (walls and smokes cut the field of view); fov in config/rules/senses.py.
- 12.11.2026 · Christian · Weapons · Every weapon gets the alternate fire of its Valorant counterpart; the knife has no headshots and deals double damage from behind; sniper zoom centres on the crosshair inside a scope circle; no-scopes are inaccurate.
- 12.11.2026 · Claude Code · Weapons · Alternate fires of the sidearms are from memory: Thorn, Hornet, Bull, Fan none; Lynx and Kite aim down sights 1.25x. Christian to confirm against Valorant.
- 12.11.2026 · Claude Code · Movement · Jump velocity 5.4 m/s (about 1.05 m) so crates and platforms are reached only with a full jump; walking climbs 0.25 m, landing needs the feet within 0.15 m of an edge; full-height walls are never climbed. Safe landing speed 8.5 m/s so jumping off a crate does not hurt.
- 12.11.2026 · Claude Code · Sound · Direction by panning and tone: sounds behind the listener and behind walls play a muffled copy (moving-average low-pass) and a little quieter. Mix values in config/client/sound.py.
- 12.11.2026 · Christian · Abilities · Abilities that need aiming or have a right-click variant are cast like in Valorant: the key takes them in hand, left click casts, right click casts the variant, the same key, a weapon key or Esc puts them away. Abilities without aiming are cast at once.
- 12.11.2026 · Christian · Lobby · Lobby rules are set in the lobby (host, or the player against bots), not in the player settings: rounds to win, overtime win by two, play out all rounds, all-around sight, sound rings, allow cheats with infinite ammo, infinite abilities, invincibility (players, not bots) and bullet tracers. Defaults in config/settings/lobby.py; clients receive them with every snapshot.
- 12.11.2026 · Christian · Interface · Menus and HUD follow Valorant's layout and colours (dark slate, red accent, teal/red teams, pale yellow ultimate) in pixel art. Deviation: the top bar of a match (team portraits, timer, score) moves to the sides (own team left, enemies right) and the bottom centre, so the view ahead stays free.
- 12.11.2026 · Christian · Content · Balance changes go into patch files (config/patches, applied in file-name order, notes on the Career page) instead of editing the content files; ready-made abilities live in config/content/abilities; content can be reloaded from the escape menu in own matches. The escape menu holds the full settings; every Enter action has a button.
- 12.11.2026 · Claude Code · Maps · Map keys in English (workyard, alley, harbour); the tile folders keep their names through "art". Workyard and Harbour got sight-blocking walls in front of both spawns (spawn rooms with side exits): before, the spawns saw each other across the map and bots killed players 0.5 s after the barriers dropped. A test keeps every map free of spawn-to-spawn sight.
- 12.11.2026 · Christian · Abilities · Throwables (flashes, grenades, target="throw") show no landing preview, only a throw cursor; they fly a hidden share of the cursor distance (config/rules/combat.py abilities.throw_factor, 0.8, per ability throw_factor), so judging the throw is a skill. Placed abilities with a targeting view (smokes, teleports, ultimates) keep their preview.
- 12.11.2026 · Claude Code · Rules · Taken over from Valorant (researched 12.11.2026): loss streak 1900/2400/2900 and 1000 for survivors who did not finish the objective; selling items in the same buy phase while still held (a new gun drops the old one, selling brings it back if it still lies there); tagging (72.5 % slow for 0.35 s after a bullet hit, 25 % through walls; the duration is an estimate, no official number found); assists; two ultimate orbs per round (hold F 1 s, gone after the plant); shared team vision and last known positions on the minimap; kill counter sounds 1-5; round titles Ace, Clutch, Flawless, Thrifty; match point and last round of the half banners; surrender from the escape menu; players block each other.
- 12.11.2026 · Christian · Sight · Props lower than head height (config/content/prop_heights.py, head_height in config/rules/senses.py) do not block sight or shots. A standing player's head shows over head-high cover (head shots pass, the rest is blocked); crouching behind it hides the player.
- 12.11.2026 · Claude Code · Abilities · Multi-placement (multi=N): left click marks up to N points within range, right click places them all; one charge per point, an ultimate pays once. Juniper's Cloudcast uses it.
- 12.11.2026 · Claude Code · Code · Weapon and armor keys are plain English descriptions (pistol, assault_rifle, heavy_sniper, light_shield …); the sprites keep their file names through "art". Real weapon names of another game are not used as identifiers or display names.
- 12.11.2026 · Claude Code · Maps · Ascent rebuilt at real scale (131 × 137 m): footprint traced from the tactical map in the official minimap projection (1656 px = 142.86 m), one grid character per square metre in gameplay/data/maps/ascent.py, features placed in reference pixels. Floor levels from gameplay screenshots: A site plateau one storey above the front (stairs, jumpable ledge), A Heaven/Rafters two storeys above the site (stairs from the A connector, drop down to the site, too high to jump onto), A Garden stairs down to Tree, Mid Top/Catwalk/Cubby one storey above Mid Courtyard (stairs at the catwalk, steps from Mid Top), arch stairs up to Mid Bottom, the defender side (spawn, connectors, Plaza, Market) one storey above B site with the CT stairs and the log steps to the Market door platform. Deviations: Hell is the site floor under the Heaven edge (one walkable floor per point); the A Window glass does not break; both bomb doors keep Val2d's reversible F door; relative heights of rooms not visible in the screenshots (lobbies, A Main, B Main) are kept on one level.
- 12.11.2026 · Claude Code · World · Floors may lie on any level: full walls are taller than every floor, cover and platform sides stand on the floor under them (Wall.base, Wall.top), ramps may join two levels ("rise", "low", "high"; MapBuilder.stairs), platforms can keep the floor art (mat "floor"). Bullets and sight ignore platform sides. Bots path over heights: a step may rise at most 0.3 levels per half metre, drops are free; the search covers the whole grid.
