# Archived custom agents

This archive preserves the 30 original Val2d agents, including Kestrel and Marrow. It contains their
configuration files, sprite strips, ability icons, design sources, and the original directional sprite handover.

The game and Windows build read agent assets and configuration from the top-level `assets/` and `config/` directories.
The archive is outside both paths. The original file naming and generator inputs are retained for reference.
